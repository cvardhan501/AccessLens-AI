AccessLens AI: Civic Accessibility Auditor Governed by Strands Decider 2B Policy Gatekeeping

Description (max 512 characters):
AccessLens AI is an open-source civic accessibility auditing agent using Playwright and axe-core 4.13.0, governed by Strands Decider 2B (#policy). Rather than applying blind automated code fixes to public portals, AccessLens AI uses calibrated probability thresholds (70% confidence floor, 85% for critical issues) to route violations into advisory patches, DOM context reports, or human review with a 4-step manual testing protocol. Verified with 68 passing offline tests and multi-layered SSRF defense.
